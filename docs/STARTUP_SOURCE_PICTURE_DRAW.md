# Startup picture presentation boundary

The normal startup path can present a labelled static fallback from user-owned game data. That fallback is not a timed intro frame and does not establish scene activation, camera selection, cut progression, or menu entry.

A live picture requires an admitted scene frame and the owning renderer's accepted draw path. Do not convert a diagnostic or fallback image into evidence of parity.

This document omits retail assets, payloads, identifiers, measurements, and private executable analysis. See [INTRO_AND_MENU_PLAN.md](INTRO_AND_MENU_PLAN.md) for current delivery status.
