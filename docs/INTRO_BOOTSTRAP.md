# Intro bootstrap boundary

Normal startup does not yet play the authored intro. It can show a labelled static fallback, but it does not advance a scene timeline, start intro audio, or enter the main menu.

The project still needs one owning runtime session to connect validated input, lifecycle updates, camera state, audio, ordered draw submission, and teardown. Diagnostic tools remain separate from normal playback.

This public page omits original file names, resource records, field layouts, values, counts, screenshots, and executable-derived observations. Detailed analysis remains in private research storage.
