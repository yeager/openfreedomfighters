# Private intro lifecycle receipt

A local review receipt may admit an independently reviewed, source-free lifecycle record. It remains inert: installing or loading the receipt does not activate an intro, scene, camera, renderer, or startup route.

The validator accepts only bounded, regular, non-symlink files in the user's private application data directory. It rejects malformed, oversized, duplicate, or unsupported input and never stores raw observations.

Detailed traces and original-executable observations remain outside the repository. A separate project-owned behavior contract is required before any runtime connection is made.
