# Scene transform boundary

Normal world-scene rendering is not yet connected to an admitted runtime scene. Diagnostic previews are project tools and do not establish gameplay transforms or parity.

The project must join object ownership, placement, camera state, draw ordering, and backend submission through explicit project-owned interfaces before it can produce a normal world frame. The current diagnostic path is not a substitute for that frame producer.

Original executable analysis, object identities, renderer relationships, transforms, and installation observations remain in private storage. Public claims are limited to source-code behavior and project-authored synthetic fixtures.
