# Private intro observer preparation

This tool validates a fixed, source-free plan for a separately maintained private observer. It does not locate, launch, attach to, or instrument a game process and does not read game files or executables.

Inputs and outputs must remain outside the repository in owner-only storage. The validator rejects unknown fields and malformed records. A validated plan is not evidence of runtime behavior and cannot enable normal startup.

Do not publish observer output, original-executable analysis, asset identities, values, screenshots, or traces.
