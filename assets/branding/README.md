# OpenFreedomFighters splash artwork

`openfreedomfighters-splash.png` is original project artwork generated for
OpenFreedomFighters on 5 September 2026. It is not extracted from Freedom
Fighters and contains no retail game asset. The project owns and distributes
this artwork under the repository's MIT license. The current revision was
generated with the built-in image generation tool using the user-supplied
poster only as a palette and mood reference, not as a source to redistribute.
It is branding artwork, not a screenshot or evidence of rendering fidelity.

`openfreedomfighters-splash.bmp` is a lossless runtime derivative of that PNG.
It is kept beside the source so SDL can decode the splash without an additional
image library. Both files have 1672×941 pixels. The BMP was produced by loading
the PNG with Pillow 11.3.0, converting it to RGB, and saving it as a Windows BMP.
The requested resolution was 3840×2160; the generator returned 1672×941.
The files retain that native resolution without artificial upscaling.
